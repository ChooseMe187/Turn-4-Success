# Turning 4 Success

Public property maintenance and quote-request site. Run `npm test` to verify the source. The Actions workflow deploys `public/` and the Pages Function to the existing `turning4success-staging` project after configuring the `CLOUDFLARE_API_TOKEN` Actions secret. Configure `RESEND_API_KEY`, `QUOTE_FROM` and `QUOTE_TO` in Cloudflare Pages production settings before deploying. Send a test quote with a photo and confirm receipt in the business inbox.
